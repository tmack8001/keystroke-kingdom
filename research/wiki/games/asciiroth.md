*The Tombs of Asciiroth* is a browser-based ASCII/font-character puzzle-adventure game
by **Alx Dark**, released as version 0.7 on **July 24, 2009**, hosted at
icculus.org (Ryan C. Gordon's open-source project hub). It renders its "extensive
world of font-based abstraction" — the developer's own phrase — entirely in text
characters, blending arcade, puzzle, and exploration gameplay with light RPG elements
in later versions. It is **single-player**, playable in-browser (Firefox/Chrome/
Safari/IE8) or as a desktop Adobe AIR app, and ships with a built-in map editor for
user-made scenarios. The developer's own tagline — *"If it looks a little old school,
it's only because I've been trying to make this game since 1980"* — makes the game's
own self-positioning explicit: a deliberate homage to the early-1980s ASCII-roguelike
aesthetic, built decades later.

## The facts

- **Developer:** Alx Dark. **Version fetched/dated:** 0.7, released July 24, 2009.
- **Platform:** Web browser (Firefox, Chrome, Safari, Internet Explorer 8) via Google
  Web Toolkit, with a parallel desktop build via Adobe AIR for Windows/Mac/Linux.
  Built with Eclipse and Ant; open source under the Apache 2.0 license, with source
  available via SVN.
- **Genre:** primarily puzzle/adventure — the developer's own description is "arcade,
  puzzle and exploration-style game play." Later versions added "pieces for more
  RPG-style play" as a complement to, not a replacement for, the puzzle core.
- **Single-player, confirmed exclusively.**
- **Main scenario:** "The Tombs of Asciiroth" — the title content this version ships
  with — alongside a tutorial and a built-in map/scenario editor that let players
  create and share their own content, the same "engine + user-made-world" pattern
  MegaZeux popularized (though there is no evidence found this session of any direct
  lineage or influence between the two projects — they are independently-developed,
  aesthetically-similar titles, not confirmed to share history).
- **Hosting context:** icculus.org is Ryan C. Gordon's ("icculus") personal/project
  hosting site, founded after his work porting Loki Software's Linux game ports
  (following the 1999 "Loki Hack" contest at the Atlanta Linux Showcase) — it hosts
  a range of free/open-source software projects, of which Asciiroth is one. This
  places Asciiroth in an open-source, hobbyist/indie-developer tradition rather than
  a commercial one.
- **Save/persistence:** supports Google Gears or HTML5 database-backed game saves —
  period-appropriate late-2000s browser storage technology.

## Reconciliation with the "clans/EverQuest" memory

Nothing found this session about Asciiroth, MegaZeux, or the ummagumma-style
hobbyist ASCII-RPG realm generally describes shared/networked worlds, guilds, or
any multiplayer social structure. This realm is a strong, well-confirmed match for
**the visual and interaction aesthetic** Trevor is describing (overhead or
adventure-style movement through a world rendered entirely in colored text
characters) but not for the separately-remembered clan/alliance/EverQuest-adjacent
social layer. See [[early-graphical-mmorpgs-1990s]] for the fuller ranked comparison
against genuinely multiplayer 1990s candidates (Island of Kesmai, Legends of Kesmai,
Neverwinter Nights 1991, Meridian 59) — the working hypothesis remains that the
"look" memory (ASCII/ANSI text-character world) and the "clan" memory (a shared,
joinable social structure) are either two separate childhood games being recalled
together, or the clan feeling came from a community/sharing layer (like DigitalMZX's
forums around MegaZeux) rather than from in-game networked play. Neither this page
nor [[megazeux]] resolves that tension — they narrow the aesthetic half of the
question and rule out this specific realm as the source of the social half.

## Downstream design flags — One Rule and kid-safety

No specific combat-death or punishment mechanic was documented for Asciiroth in the
material fetched this session (its own description emphasizes puzzle/exploration
over combat, which is a gentler starting point than MegaZeux's stat-combat RPGs or
[[nethack]]'s permadeath). Even so, apply the same standing rule as every ASCII-genre
reference in this wiki: **KEEP** the font-character world-rendering aesthetic and the
exploration/discovery loop; **VERIFY AND STRIP** any death/failure state before using
specific Asciiroth content as a direct model, since this session did not fetch deep
enough into actual gameplay/mechanics detail to confirm one doesn't exist.
