Laserdisc arcade games used Pioneer laserdisc players for NTSC full-motion-video playback,
controlled by custom hardware that selected branching video segments based on player input
timing — producing gameplay that looked like a full theatrical cartoon rather than any
raster, sprite, or vector game of the era.

## In this game

[[dragons-lair]] (Level 7, Act 2 "The Computer Wing") is Keystroke Kingdom's example of this
technique — Advanced Microcomputer Systems/Cinematronics licensed Don Bluth's ex-Disney
animation studio to produce ~22 minutes of hand-drawn cel animation played back from
laserdisc, with player input selecting which branching segment played next rather than
controlling a character in real time. The level's design brief explicitly wants this visual
leap to feel as jaw-dropping as it did in 1983.

## The facts

- Dragon's Lair (1983): Pioneer laserdisc player, custom arcade hardware selecting
  branching video segments by input timing. Not a raster/sprite/vector game in the
  traditional arcade sense — essentially an interactive film. ~22 minutes of animation,
  ~50,000 hand-drawn drawings, ~$1.3M of a ~$3M total budget.
- Famous for charging 50 cents per play instead of the standard quarter — well-documented,
  but likely not verifiably the literal first game to do so (see [[dragons-lair]]'s
  correction: Missile Command briefly used a factory 50-cent default; some accounts also
  cite Pole Position around the same period).
