IDDQD is the god-mode (invulnerability) cheat code in id Software's *Doom* (1993),
distinct from IDKFA (the weapons/keys/ammo cheat) — one of gaming's most widely
recognized cheat codes.

## In this game

Typing `iddqd` is refused, on principle: the game responds `GOD MODE DENIED. THIS GAME
NEVER TAKES LIVES.` This is a deliberate joke built on Keystroke Kingdom's own
no-punishment design law (see CLAUDE.md's "one rule that overrides everything") — the
game has no lives to grant invulnerability from in the first place, so god mode is
refused as a punchline rather than granted. Dangling link: Doom (the game itself, if
covered by another agent's video-game-history domain). See [[hacker-culture]] and
[[easter-egg-culture]].

## The facts

- **December 1993:** *Doom* releases.
- IDDQD grants god mode (invulnerability), explicitly distinct from IDKFA, which grants
  full weapons/keys/ammo — confirmed by the community-canonical DoomWiki reference.
- IDDQD's meaning and Doom's December 1993 release are further corroborated by Know
  Your Meme.
