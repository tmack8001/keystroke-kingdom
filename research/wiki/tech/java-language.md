Java is the programming language begun at Sun Microsystems in June 1991 as "the Green
Project," first called **Oak** — after a tree outside James Gosling's office — and
renamed **Java** in early 1995 when the lawyers found Oak was already trademarked. The
replacement name came out of a brainstorming meeting where people were drinking Peet's
**Java** coffee, and — this is the honest part — *nobody on the team agrees about who
said it first.* The toolkit you download to write Java is the **JDK**, the Java
Development Kit; **JDK 1.0** shipped **23 January 1996**.

## The facts

- **June 1991 — the Green Project.** The Computer History Museum's Gosling profile:
  *"In June 1991, Gosling, Mike Sheridan, and Patrick Naughton initiated the Java
  language project (called 'The Green Project' at the time)."*
- **Oak came first, and it was demonstrated publicly.** CHM: the initial language was
  designated **"Oak"** and *"was first demonstrated on September 2, 1992, in the form of
  a sophisticated handheld media controller, called Star-7."* ⚠️ **Created-vs-shipped
  discipline:** Oak is not a rejected draft name that never left the building — it was
  the name on a working demo for more than two years before the rename.
- **The tree.** The "oak tree outside Gosling's office window" origin for the *Oak* name
  appears in every popular retelling but was **not confirmed by any institutional source
  fetched this session** — CHM names Oak without explaining it. Treat as
  **widely-repeated, weakly-sourced**; see the caveat below before it reaches a card.
- **Why the rename.** Frank Yellin, quoted in the JavaWorld/InfoWorld team interview:
  *"The lawyers had told us that we couldn't use the name 'OAK'"* — it was already
  trademarked (by Oak Technology). The brainstorm that produced the replacement was
  around **January 1995**.
- **The coffee — attributed, contested, and charming for exactly that reason.** Arthur
  van Hoff's account is that **Chris Warth** said "Java" *"while he was drinking a cup
  of Peet's Java"* — offering it as an example of a name that would *never* work. Warth
  himself declines the credit: *"I don't claim to be the one who first suggested the
  name."* Gosling recalls *"about a dozen people got together to brainstorm."* Product
  manager **Kim Polese** test-marketed the candidates, found Java drew the best
  reactions, cleared it with the lawyers, and says flatly: *"I named Java."*
  **Popularizer-vs-inventor, in miniature: the sourceable claim is that the name came
  out of a room where people were drinking Java coffee — not that one named person
  coined it.** A card must not pick a winner the sources do not.
- **"Java" the coffee is "Java" the island.** The coffee name is the Indonesian island;
  this is the ordinary etymology of the American slang word for coffee. *(Asserted in
  search summaries only this session; the card does not need it and should not carry it
  as a fact.)*
- **The JDK.** JDK = Java Development Kit, the compiler-and-libraries bundle a
  programmer installs to write Java. **The first version was released 23 January 1996.**
  (Wikipedia, corroborating the same date returned by search; no Oracle/Sun primary was
  fetched this session — see below.)
- **Silk nearly won.** The other finalist name was **Silk**, *"as in what you spin webs
  with."* Trademark availability decided it. *(Search summary of the same JavaWorld
  interview; the InfoWorld fetch confirmed the interview and the trademark constraint
  but this specific alternative was not in the fetched excerpt — flagged, not asserted.)*
