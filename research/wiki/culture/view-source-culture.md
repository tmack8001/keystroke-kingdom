"View Source" — the browser feature letting anyone inspect a webpage's underlying
HTML — and its later descendant, the JavaScript console (created by Brendan Eich), are
widely credited as the on-ramp that let a generation of self-taught developers break
into web development simply by hopping from page to page and reading the code behind
it.

## In this game

Keystroke Kingdom's console banner (styled after [[wopr-wargames]]) and the binary HTML
comment atop `index.html` (which decodes to "SHALL WE PLAY" — see [[ascii]] for the
binary-to-text mechanism) are both direct expressions of this tradition. The design
rationale, per the hub doc: "Opening the browser console is a child's (or parent's)
first genuine hacker act, which is why the console carries the only hints." See
[[hacker-culture]] and [[easter-egg-culture]].

## The facts

- View Source is documented as a foundational, low-barrier entry point into web
  development: "If not for that simple tool, many developers would have had no way to
  break into web development themselves... web developers were able to get their start
  simply by hopping from page to page and taking a look at the code directly."
- The JavaScript console, created by Brendan Eich, is covered as a parallel
  foundational tool in the same source.
- This claim rests on a single strong source (*The History of the Web*, a
  citation-quality, book-published web-history project) — targeted searches for a
  second corroborating source (Wired, Ars Technica, BBC, MDN) came up empty on this
  specific angle, so it stands as the anchor citation rather than being padded with a
  weaker second reference.
