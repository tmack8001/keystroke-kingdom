The Konami Code (↑↑↓↓←→←→BA) was created by Kazuhisa Hashimoto as a testing aid for the
1986 NES port of *Gradius*, because he found the arcade original too difficult to test —
meant to be removed before shipping, but left in by accident. It became internet-famous
for granting "30 lives" specifically in *Contra* (1988), a later and separate use of the
same input sequence.

## In this game

The Konami Code grants 30 extra *stars* in Keystroke Kingdom, not lives — "we grant
light, not lives," consistent with the game's no-punishment design law (see
CLAUDE.md). Dangling link: [[contra]] (the game most associated with the "30 lives"
meme, if covered by another agent's video-game-history domain). See
[[hacker-culture]] and [[easter-egg-culture]].

## The facts

- **1986:** the code first appears in the NES port of *Gradius*, created by Kazuhisa
  Hashimoto.
- Hashimoto himself, in a translated interview (Nintendo Life), described adding the
  code during the Gradius NES port because the arcade original was too hard for him to
  test.
- **1988:** *Contra* uses the same input sequence to grant 30 lives — this later,
  separate use is the specific origin of the "30 Lives Code"/"Contra Code" nickname, not
  Gradius itself.
