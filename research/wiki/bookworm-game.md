Bookworm is a word-building puzzle game published by PopCap Games, released February 25,
2003, in which players form words from a grid of letter tiles. It is not a typing tutor —
it assumes the player already knows how to type and tests vocabulary and spelling instead.

## In this game

Bookworm shares a single point of philosophical DNA with Keystroke Kingdom: the idea that
"typing a real word you can read is a double win," which echoes Keystroke Kingdom's own
[[touch-typing-pedagogy|Word Bank Principle]] — real words only appear once enough letters
are learned, and typing a decodable word is treated as a moment worth protecting, never
interrupted. Beyond that emotional resonance, nothing about Bookworm's structure carries
over: it is a vocabulary/spelling game built on the assumption of existing typing fluency,
not a keyboard-learning curriculum, so it contributes no lessons to the key-progression
design documented in [[touch-typing-pedagogy]].

## The facts

- Publisher: PopCap Games.
- Release date: February 25, 2003.
- Genre: word-building game from letter tiles — vocabulary and spelling, not touch-typing
  instruction. Assumes the player can already type.
